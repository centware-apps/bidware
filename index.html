Install on iPhone

Open BidWare
  1. Open this page in Safari (the blue compass). Other apps’ built-in browsers can’t install it.
  2. Tap Open BidWare above.
  3. Tap the Share button at the bottom of the screen.
  4. Scroll down, tap Add to Home Screen, then tap Add.
  5. Open BidWare from your Home Screen icon from now on, so your data stays in one place.
Apple doesn’t allow downloading apps from outside the App Store, so on iPhone BidWare installs this way. It looks and works like an app, opens full screen and works with no internet.

Install on Android

Download BidWare for Android
  1. Tap Download. If your browser warns that this type of file can harm your device, tap OK or Download anyway. Every app file shows this warning.
  2. Open the file when it finishes (tap the notification, or find it in Downloads).
  3. If Android says it can’t install from this source, tap Settings, switch on Allow from this source, then press back.
  4. Tap Install. If Play Protect asks, tap More details, then Install anyway.
  5. Tap Open. You can switch “Allow from this source” off again afterwards.
Prefer not to download a file? Open BidWare in Chrome, tap the ⋮ menu, then Install app.
Your data lives only on your phone. Your current job saves itself on your phone. Use Save BidWare file inside BidWare to keep a copy of any job, since saved jobs can’t be recovered if you delete the app.
